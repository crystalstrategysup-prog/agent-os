# Bug report

Use the **Causal debugging** section of the selected AgentOS `docs/PROCESS.md`
(installed `resources/docs/PROCESS.md`, located with `agentos resources`).
Keep experiment rows in this record or link the existing assigned-work journal.

## Date and version

[REQUIRED] Pin the observed environment, source and loaded runtime separately.

## Reproduction

[REQUIRED] Record the user action, data/fixture, initial state, effective settings
and load. State explicitly when reproduction is unavailable or unsuccessful.

## Expected result

[REQUIRED] State the expected result and observable success/failure criterion.

## Actual result

[REQUIRED] Provide facts and sources.

## Impact

[REQUIRED] Provide facts and sources.

## Evidence

[REQUIRED] Link the baseline and compact experiment journal in PROCESS, including
primary evidence for every run. Separate hypotheses, observations, confirmed
conclusions and unknowns; state the scope of each conclusion.

## Correction and next step

[REQUIRED] Identify the exact correction or mitigation, its verification stage
as defined in PROCESS, remaining uncertainty and next responsible actor/action.
