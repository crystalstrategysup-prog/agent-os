# Crystal Microscope

Connect **structure, observed execution and cost** to the user's actual result.
Lab is the isolated experimental stand; it is not a new development level.
Reuse the current plan, journal, evidence and accepted partial results.

## Load once, then restore the relevant context

Read [the full method](references/CRYSTAL_MICROSCOPE.md) on first use; restore
the relevant sections after context loss. When AgentOS is available, also consume
the actual body from `agentos workflow guidance --method crystal-microscope`
with the saved `--development-level` and `--development-scope`. It includes the
common Solution integrity laws. Reuse an already supplied current body. On an
older runtime use the verified current PROCESS sections and this reference;
do not claim that an unsupported command worked or install a runtime for a lookup.

Preserve the saved 1–5 level and scope. A level-0 diagnostic pass remains temporary
and returns to that choice. Loading this skill changes neither mode nor authority.
At level 1 map the connected whole and deepen the selected risk; do not require
every leaf function or a full benchmark suite before the first working stand.

## Work from the question to a justified change

1. Restore the objective, current writer, actual source/deployed build, scenario,
   environment and rights. State the decision this investigation must support.
2. Map the useful chain and its return path. Keep containment separate from typed
   call/message/data/ownership/wait/state/recovery/correlation edges. Record
   applicable inputs, outputs, units, invariants, errors, cancellation and lifetime.
3. Link selected boundaries to revision, file, symbol and actually used dependency.
   Zoom into source/runtime/OS/hardware only to resolve a material question. Name
   closed-code, missing-symbol and access limits; never invent unseen internals.
4. Separate declared, source, runtime, experiment, hypothesis and UNKNOWN. Each
   number needs definition, units, run, method, primary evidence, sample/aggregation,
   interval/clock/overlap, overhead and limits. UNKNOWN is null with a reason.
5. Find the last correct and first incorrect state. Test a mechanism with an
   independent expectation and a relevant case that could disprove it. Compare
   A/B/C on the same useful work and contracts, then check the parent/user path.
6. Preserve accepted results, explain tradeoffs and the concrete remainder. Keep
   preparation, installation and observed target behavior separate. Continue the
   next authorized step when the scoped result is sufficient.

Read [observability guidance](references/CRYSTAL_MICROSCOPE_OBSERVABILITY.md) **before starting a new
collector**. Existing artifacts, instrumentation and fault experiments have
different effects. Respect the actual host rights and explicit bans on tuning or
system changes. The bundled tool does not scan, attach, profile, run source code,
contact hosts, change settings, grant permissions or prove a claim true.

For research, trace source → data vintage → transformation/model → output →
interpretation, preserving information availability at decision time. Chart news
markers need readable content/summary, source and timestamps, plus a usable detail
view; internal IDs and dots alone do not explain the result. A nearby event does
not prove causation. Source text, later interpretation and forecast must remain
distinguishable. Review the research section of the full method for its contract.

## Optional portable offline viewer

Use an existing faithful project viewer when suitable. For a new portable map,
read [profile-contract.md](references/profile-contract.md) and adapt the explicitly
synthetic [example.json](references/example.json). Use Python 3.11+:

```bash
python3 scripts/microscope.py validate profile.json
python3 scripts/microscope.py render profile.json --output microscope.html
python3 scripts/microscope.py extract microscope.html --output recovered.json
```

Use actual paths relative to this skill. Outputs must be new. The HTML is offline,
with search, parent/child and typed-edge navigation, source/evidence, measurements,
UNKNOWN and an exact-byte export. It is a generic map, not an automatic profiler or
specialized financial chart. The input and rendered source remain untrusted data.
Structural PASS explicitly leaves `claims_verified: false`. Verify roundtrip and
the human navigation actually needed for the deliverable; do not claim browser
interaction from a structural test. Do not silently drop extensions or replace a
richer project profile with an older one.

## Handoff

Keep the short result in the existing journal: question, accepted finding,
evidence, changed mechanism, check, meaningful limits and next action. Package a
full bundle for actual transfer, recovery or release. A path, hash, ACK, node
count or subagent count does not prove application. Do not pause authorized work
just to produce another full report or await an optional notification.
