# agentos-safe-update

Read the relevant installation, update, and compatibility sections. Verify source and wheel
hashes, the current pointer, disjoint core/user paths, and backups. Run the
installer plan first; apply only to the exact verified target. Do not use sudo,
network downloads without current owner authority, another runtime, or global
auth, model, or trust edits.

Before expensive checks, select their scope once with
`python -B -m agent_os.investigation --update-plan REQUEST.json` and the
`docs/UPDATE_VERIFICATION.md` contract. Verify the retained receipt bytes and
complete dependency/test/contract/environment pins before declaring reuse.
Reuse an unchanged isolated regression or rollback rehearsal; rerun affected or
unproved scopes. A version change alone does not invalidate every component.
The current artifact, compatibility and installed readback always need fresh
checks. Planning never authorizes installation or retries an unknown effect.

Do not repeat source discovery, full suites, rollback rehearsals, integration
rewrites or reports merely because a new release exists. Read bounded relevant
fragments, batch independent reads and retain one result. Repeat only for changed
inputs, a relevant failure or an explicitly bounded reproducibility question.
Measure the limiting stage before attributing delay to the network or tools.

Overlay import is create-only: reconcile a conflict instead of overwriting.
Migrate config only with backup and readback; block unknown future schemas.
After a core switch, refresh only changed managed AGENTS/skills; preserve a
conflicting target rather than forcing an unchanged rewrite. Test new CLI
processes; a fresh native client is needed only for changed client integration
or a native-adoption claim. Keep the previous release. Rehearse rollback in an
isolated contour when its pinned installer/runtime/schema/fixture dependencies
changed or retained evidence is insufficient; otherwise retain that proof.
Report the result, a material limit and its next action concisely, with a link to
retained evidence. Do not narrate unchanged procedures. Report target status
separately. Native hooks remain disabled. Rollback must not run a beta.4-or-earlier
integration generator or restore hook backups.

The installed `resources/docs/PROCESS.md` and README are normative; locate them with
`agentos resources`. Project gates apply to real changes. Reading requires no
intake or observation. Native hooks remain excluded and must not be enabled or
restored. Neither CLI output nor profile text grants external authority.
