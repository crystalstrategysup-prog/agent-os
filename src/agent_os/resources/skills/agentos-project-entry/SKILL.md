# agentos-project-entry

1. Прочитай актуальные AGENTS/README, dossier/roadmap/stage и нужные записи overlay index.
2. Запусти project questions; известные данные подтверди источником, спроси только значимые неизвестные.
3. Новый проект: сначала исследование, затем init с purpose/current_state/boundaries/constraints.
4. Подготовь answers по schema/examples, exact scope/authority/criteria/checks.
5. Запусти enter для настоящих session/turn; при продолжении --resume-task.
6. Передай selection documentation-planning. Draft не READY.
Read-only запрос: project observe с реальными источниками, никакой записи в проект.
Выход: task ID / required docs / missing facts либо observation receipt; не implementation.
Stop: нет источника полномочий, новый cwd, stale turn, неожиданный active task.

Нормативная основа: установленный resources/docs/PROCESS.md и README; путь — `agentos resources`.
Hook/CLI gate нельзя выключать пользовательской настройкой. Навык не заменяет native hook trust.
