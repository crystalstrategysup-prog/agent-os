# AgentOS project baseline — release snapshot, not live status

Purpose: give agents and humans a documentation-first project lifecycle, physically separate
public code and private data, source-bound checks and truthful closeout. The public source
repository is itself the exemplar: docs/agentos/DOSSIER.md, ROADMAP.md and stage documents
are supplied in the public source. Local `.agentos/` receipts are excluded from public
source archives and the wheel; sanitized evidence travels separately when needed. The
installed wheel contains universal mechanisms and this frozen overview, not a mutable
shadow copy of project state.

0.5.0-beta.1 is historical context; 0.5.0-beta.6 is a local source candidate.
F02/F03 added governed intake/docs/evidence and separate overlay/offline
install/rollback. F04 is independent target verification, publication and
installation. Private executable provider parity must be established separately before retiring
an existing runtime. A new maintainer opens the maintained repository, reads its current dossier
and roadmap, and starts a fresh task; no historical receipt confers present authorization.

The full immutable package verification result belongs to the delivered handoff; this overview
is not a claim that a specific release is published, a Mac is updated, or native hooks are active.
