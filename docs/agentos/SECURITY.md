# AgentOS engineering security

## Assets
Protect user overlays, credentials, project business data, active task ownership, immutable history and working services. Public source contains only reusable code, contracts and synthetic fixtures.

## Threats
Relevant failures include stale source selection, path escape through links, malformed or oversized metadata, accidental secret output, a misleading health PASS, reader loss on update, concurrent writes and duplicate effects after UNKNOWN.

## Authority
The current owner request defines the work. CLI records, profiles, manifests and supplied authority strings are evidence references, not authenticated permission grants. Preserve operating-system permissions, target leases and existing protected-effect controls. Read-only diagnostics requires no new task or bootstrap. Product changes follow the documented admission and review path.

## Secrets
Emit metadata and content hashes only in project diagnostics. Do not print config payloads, subscription URLs, capabilities or raw session contents. Do not modify authentication, permissions, model/provider configuration or native hooks. Test against synthetic local roots and review every public Git addition before publication.
