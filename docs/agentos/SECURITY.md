# Guarded launch security

Assets: public source/contracts, immutable release identities, selected private knowledge, current executor authority and durable task evidence. Public packages must contain no credentials, owner/host identifiers, private report routes, user overlay, transcripts or runtime/task records.

Threats: premature business dispatch, guessed defaults or aliases, wrong binary/account, stale receipts, incorrect Screen/worker identity, duplicate writers, arbitrary RPC methods, leaked provider diagnostics and false acceptance. Bound requests, metadata, pagination, deadlines, tool probes and retained identities; refuse unsupported dependent actions.

Authority comes from the current human instruction and exact target controls. Profiles, source documents, READY, catalog advertisement and ACKs grant no new rights. Financial, security, credentials, destructive, DB and production boundaries remain intact. No policy/auth/model setters or automatic restarts are introduced.

Native hooks stay disabled. Retired private kernel code is excluded. Diagnostic receipts retain only finite safe fields; never copy raw auth/provider text or unrelated transcripts. Source: docs/SECURITY_MODEL.md and the reviewed launcher contracts.
