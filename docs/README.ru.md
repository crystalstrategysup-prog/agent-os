# Crystal AgentOS — русская навигация

AgentOS — публичный фундамент для системной работы агента с проектом. Каждый
продуктовый этап начинается с актуальных досье, дорожной карты и документа
этапа; короткая входная анкета выбирает только нужные дополнительные документы.
Завершение требует проверок текущего результата и актуализации документации.

Версия beta `0.5.0-beta.3` (Python `0.5.0b3`). Ядро содержит общий код, схемы,
шаблоны и навыки. Настройки и знания пользователя живут отдельно, по умолчанию
в `~/.agentos-user`; обновление ядра их не удаляет. См. [границу двух слоёв](FOUNDATION_OVERLAY.md),
[совместимость](COMPATIBILITY.md) и [установку](INSTALL_UPDATE.md).

На macOS/Linux установка из проверенного публичного Git tag: создать Python 3.11+
venv, выполнить `python -m pip install .`, затем `agentos init` и `agentos doctor`.
Команда `pip install crystal-agent-os` пока не работает: страницы проекта в PyPI
нет. Точный путь, SHA и release notes публикуются вместе с beta. Windows installer
не проверен и не заявлен поддерживаемым.
