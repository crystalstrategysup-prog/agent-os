# Crystal AgentOS

**Свободный локальный управляющий слой для персональных AI-агентов.**

AgentOS добавляет агенту то, чего недостаточно получить только от модели:
границы полномочий, локальную конфигурацию, классификацию задач, MCP-интерфейс,
диагностику и понятное подключение Telegram Business.

## Полная инвентаризация и обновления

Версия 0.4 добавляет ограниченную полную инвентаризацию поддерживаемых знаний
зарегистрированных проектов. В результате остаются только пути, классы, размеры
и SHA-256, без содержимого файлов; история автоматически не загружается.

AgentOS также проверяет официальные публичные теги не чаще одного раза за 48
часов активного использования. Это не фоновый демон: после простоя проверка
произойдёт при следующей команде. Никакой автоматической установки нет.

```bash
agentos inventory collect --catalog /absolute/path/projects.json --output ~/.agent-os/state/inventory.json
agentos inventory select --input ~/.agent-os/state/inventory.json --project-id my-project
agentos update-check
```

## Маршрутизация моделей и честная приёмка

Версия 0.3 детерминированно выбирает роль модели: Sol/high для координатора и
сложной проверки, Terra/medium для ограниченной реализации, Luna/low для
простых массовых операций и Astra/high только для явно критической работы
корневого агента.

```bash
agentos route-task --mode implementation --role root
agentos route-task --mode classification --role worker --complexity low
```

Маршрут — это план, а не доказательство фактического запуска модели. По
умолчанию самостоятельное делегирование выключено. Команда
`agentos assess-result --file evidence.json` не позволяет объявить работу
завершённой, пока каждый критерий не подтверждён свежим PASS-доказательством,
привязанным к текущему состоянию.

## Подключение Telegram Business

1. Если Telegram ещё нет, создайте аккаунт в официальном приложении.
2. Запросите разрешение у владельца установленного AgentOS.
3. Создайте StringSession через QR Telegram.
4. Сохраните локально одобренный файл с `API_ID`, `API_HASH`, `STRING_SESSION`.
5. Подключите Telegram Business и business bot.
6. Добавьте AgentOS в ChatGPT или другой MCP-клиент.
7. Проверьте безопасной тестовой задачей.

Внешний сайт для авторизации не требуется. Не вставляйте секретный файл в чат
с AI, issue, лог или репозиторий.

## Управление сессиями Codex из Telegram

Бот Session Hub привязан к локальному экземпляру AgentOS. Он принимает файлы
и голос от разрешённого владельца, но не создаёт автоматически отдельного
«личного» или «отчётного» бота. Для Telegram Business используется отдельный
business bot. Если нужны несколько ботов или хостов, каждому слушателю нужны
своя идентичность, секрет и явно заданный маршрут; в открытой редакции нет
встроенного брокера для нескольких хостов.

После явного включения владелец может вызвать `/start` в своём боте AgentOS и:

- выбрать последнюю или любую найденную локальную сессию Codex;
- увидеть GNU Screen на Linux/macOS и связанную с ним сессию Codex;
- создать новую persisted-сессию или новый Screen;
- отправить в выбранную сессию текст, документ, изображение или голос;
- проверить, настроено ли распознавание речи.

По умолчанию сессии ищутся в `$CODEX_HOME/sessions` или `~/.codex/sessions`;
на Windows — в `%USERPROFILE%\.codex\sessions`. Путь к сессиям и разрешённые
рабочие папки переназначаются в конфигурации. GNU Screen на Windows отсутствует,
но обычные сессии Codex поддерживаются.

Голос можно распознавать локальным Whisper без внешнего API либо через
подключаемый OpenAI transcription API. Если ни один движок не настроен, бот
честно сообщает об этом и показывает безопасные шаги настройки. Токены и ключи
нельзя отправлять в Telegram; они читаются из переменных окружения или локального
хранилища секретов. Подробности: [Telegram Session Hub](TELEGRAM_SESSION_HUB.md).
